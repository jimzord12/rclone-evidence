rclone-evidence

rclone-evidence is a personal developer tool. It uses rclone to upload test evidence (screenshots, short videos, logs) from the developer's own computer to the developer's own Google Drive, and to create share links to those files for code reviews.

It is used only by its developer, on the developer's own Google account. It is not offered to anyone else.

It requests one Google permission, drive.file: access only to the files it creates itself, never to any other file in the Drive.
